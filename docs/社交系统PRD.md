| 项目 | 内容 |
|------|------|
| 文档版本 | v1.0 |
| 项目名称 | 社交系统（Social System） |
| 技术栈 | 前端：uniapp（一套代码多端）；后端：ThinkPHP6；数据库：MySQL 5.7；缓存：Redis；运行环境：Linux + Nginx + PHP 7.4 |

## 1. 项目概述

### 1.1 项目背景与目标
构建一套集**内容社交、微商城、广告投放、支付结算、通知提醒、在线更新**于一体的多端平台。核心痛点：为用户提供"发文章做内容 + 开店铺卖货 + 投放广告"的一站式社交商业系统，同时为运营方提供完整的审核、结算、在线更新能力。

### 1.2 核心一句话目标
让普通用户能发内容、开店铺、买商品、投广告，让运营方能在后台完成审核、结算、配置与在线更新，实现可持续商业变现。

### 1.3 目标用户
普通用户、商家（商户）、客服、审核、超级管理员。

### 1.4 项目规模
完整商业项目，可长期迭代，需稳定支撑正式运营。

## 3. 功能需求

### 3.1 用户系统

#### 3.1.1 注册登录
- **注册**：邮箱 + 密码（+ 邮箱验证），发送验证邮件
- **登录**：邮箱 + 密码，签发 token 鉴权
- **找回密码**：通过邮箱发送重置链接/验证码
- **安全**：密码加密存储、登录超时、接口鉴权、防刷限流

#### 3.1.2 个人中心
- 个人主页：头像、昵称、简介、文章列表
- 会员等级：等级体系与特权
- 关注/粉丝：关注其他用户，查看粉丝
- 消息通知：站内信列表、已读/未读

### 3.2 文章系统（内容社交）

#### 3.2.1 发布
- 内容类型：图片 + 视频外链 + 文字 + emoji
- 辅助分类：分类 / 标签 / 话题
- 发布权限：所有角色均可发布

#### 3.2.2 审核机制
- 超管可设置**文章审核开关**（开启/关闭）
- 开启：由 **AI 审核**自动处理
- 关闭：需**审核或超管任一人工审核**
- 审核结果：通过 / 拒绝（附理由），结果通过**邮件 + 站内信**通知作者

#### 3.2.3 互动功能
- 点赞、评论、收藏、转发分享、浏览计数、举报

#### 3.2.4 商业化
- 打赏 / 付费阅读
- 文章内可插入商品、广告

### 3.3 微商城

#### 3.3.1 商品
- 商品类型：**主虚拟商品 + 卡密**，支持**拼团 / 秒杀 / 预售**
- 商品规格：规格 / 库存 / 多图 / 详情
- 商品由商家在商户后台管理

#### 3.3.2 订单
- 状态流转：待支付 → 已支付 → 待发货 → 已发货 → 待收货 → 已完成
- 异常：退款 / 售后 / 取消
- 超时：**10 分钟未支付自动关闭**

#### 3.3.3 商家入驻
- 用户注册后，在个人页**申请注册商户**
- 超管可设置**商户审核开关**：
  - 关闭：直接成为商户
  - 开启：审核/超管 通过/拒绝（附理由），邮件 + 站内信通知商家

### 3.4 支付与结算

#### 3.4.1 支付接口
- 支持**彩虹易支付** + **码支付**两种网关
- 超管在后台配置接口，**单选开启**
- 支持**自动切换**：检测当前接口不可用时自动切换到另一可用接口
- 支付完成走**回调**，10 分钟未支付自动关闭订单

#### 3.4.2 费率
- 超管在后台支付配置设置**全局支付费率**
- 计算方式：**在原有金额上添加百分比费率金额**
- 商户可设置费率由**用户承担**或**商户自行承担**

#### 3.4.3 提现
- 商家在商户后台设置**收款账号**（支付宝 / 银行卡，**二选一**）
- 超管可设置**自动提现的提现账单时间**（示例：22:00）
- 流程：`22:00 生成提现账单 → 商户扣余额 → 超管后台导出 → 打款 → 成功`
- 设有**最低提现金额**限制
- 需**最低提现金额**、**操作日志 + 二次确认**（资金安全）

### 3.5 广告系统

#### 3.5.1 广告来源（双通道）
- **自定义广告**：后台菜单管理，展示在用户端
- **第三方 SDK**：对接第三方广告平台（如穿山甲 / 优量汇等）

#### 3.5.2 广告位
- 广告位按月 / 季 / 年出租
- 不同位置金额不同
- 超管后台维护**广告商城**

#### 3.5.3 广告商城
- 用户 / 商家可**上传广告图片 + 广告语**，并选择广告位置与周期
- 付款后，经**超管或审核通过**，自动进入自定义广告菜单，展示在用户端

### 3.6 通知系统（SMTP + 站内信）

#### 3.6.1 邮件场景（全部需要）
- 注册验证
- 找回密码
- 商户审核结果
- 文章审核结果
- 提现打款通知
- 订单通知

#### 3.6.2 SMTP 配置
- 超管后台**可视化配置**：服务器、端口、账号、密码、发件人
- 支持**邮件模板管理**（可编辑标题/正文）

#### 3.6.3 通知渠道
- **站内信 + 邮件**双渠道

### 3.7 后台在线更新

#### 3.7.1 服务端更新
- 超管后台**拉取 GitHub 最新版本** → 在线更新后台代码
- 更新时**自动执行 SQL 迁移 + 自动备份**

#### 3.7.2 APP 端更新
- 采用 **uni-app 官方升级中心（uni-upgrade-center）**
- 支持 **wgt 前端资源热更新**（改页面/功能无需重新打包上架）
- 支持**整包更新**（原生改动时下载新包覆盖）

## 4. 业务流程（文字版）

### 4.1 商家入驻流程
```
用户注册 → 个人页 → 申请注册商户 → [审核开关?]
  ├─ 关闭：直接成为商户
  └─ 开启：审核/超管 通过/拒绝(+理由) → 邮件+站内信通知商家 → 通过则开通商户后台
```

### 4.2 文章发布流程
```
用户/商家 发布文章 → [AI审核开关?]
  ├─ 开启：AI 自动审核
  └─ 关闭：审核/超管 任一人工审核 → 通过/拒绝(+理由)+通知 → 展示
```

### 4.3 购买商品流程
```
用户选商品(普通/拼团/秒杀/预售) → 下单 → 支付(易支付/码支付，选一+自动切换)
  → 回调 → 10分钟未付自动关闭 → 已支付 → (虚拟/卡密)自动发货 → 完成
  → 可 退款/售后/取消
```

### 4.4 资金结算流程
```
用户每笔支付 → 加收全局费率%(用户或商户承担) → 货款入平台余额
  → 22:00 自动生成提现账单 → 商户扣余额 → 超管导出 → 打款(支付宝/银行卡) → 成功
```

### 4.5 广告投放流程
```
用户/商家 → 广告商城上传素材+选位置+选周期 → 付款
  → 审核/超管通过 → 展示到用户端广告位
```

## 8. 开发建议与风险点

### 8.1 开发建议（分期）
1. **用户系统 + 登录鉴权 + 角色权限**（一切基础）
2. **文章系统**（含审核流）
3. **微商城 + 支付**
4. **结算提现**
5. **广告、通知、在线更新**
6. 每模块先做后台，再对接用户端

### 8.2 风险点
- ⚠️ **支付**：易支付/码支付为第三方聚合，需自行接入回调验签，注意**掉单/回调失败**处理（补单机制）
- ⚠️ **费率加收**：加收%需考虑商品价格上限、退款时费率是否退回
- ⚠️ **自动提现/打款**：涉及资金，需**操作日志 + 二次确认**，避免误打
- ⚠️ **在线更新**：拉取 GitHub 需处理**代码冲突、备份恢复、SQL 迁移失败回滚**
- ⚠️ **审核开关**：AI 审核准确性有限，**人工兜底必须保留**
- ⚠️ **多端支付回调**：小程序/APP 支付回调与 H5 域名策略不同，需分别配置
- ⚠️ **广告审核**：素材合规审核，避免违规内容上线
