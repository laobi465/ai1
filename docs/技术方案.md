## 3. 数据库设计

### 3.1 库与账号
- 数据库：`social`，字符集 `utf8mb4`，排序 `utf8mb4_general_ci`
- 账号：`social` / `social123`（仅授权 social 库）
- 表前缀：`s_`

### 3.2 核心表清单（详见 PRD 第 5 章）
| 模块 | 表 |
|------|----|
| 用户 | `s_user`、`s_user_level` |
| 权限 | `s_role`、`s_admin`、`s_admin_role` |
| 商户 | `s_merchant` |
| 文章 | `s_article`、`s_article_category`、`s_tag`、`s_topic`、`s_comment`、`s_like`、`s_favorite`、`s_report`、`s_follow` |
| 商城 | `s_goods`、`s_goods_sku`、`s_card_secret`、`s_order` |
| 支付 | `s_payment_config`、`s_withdraw_bill` |
| 广告 | `s_ad_position`、`s_ad`、`s_ad_order` |
| 通知 | `s_email_template`、`s_notice` |
| 系统 | `s_system_config`、`s_update_log`、`s_messsage`/`s_ticket` |

### 3.3 索引与规范
- 所有表含 `create_time`、`update_time` 时间戳字段
- 外键关联字段建立索引（user_id、merchant_id、goods_id、order_id 等）
- 状态字段用 TINYINT，金额用 DECIMAL(10,2)
- 订单号、提现账单号唯一索引

## 4. 缓存与定时任务

### 4.1 Redis 使用场景
| 场景 | Key 设计 | 说明 |
|------|----------|------|
| 会话/Token | `social:token:{userId}` | 登录态，TTL 7 天 |
| 验证码 | `social:sms:{scene}:{target}` | 5 分钟有效 |
| 接口限流 | `social:limit:{route}:{ip}` | 滑动窗口计数 |
| 热点缓存 | `social:goods:{id}` | 商品详情、文章详情 |
| 首页数据 | `social:home:feed` | 缓存 60s |
| 任务锁 | `social:lock:{task}` | 防止定时任务重复执行 |

### 4.2 定时任务（crontab + TP6 命令）
| 任务 | 频率 | 说明 |
|------|------|------|
| 提现账单生成 | 每日 22:00 | 自动生成可提现余额账单 |
| 订单超时关闭 | 每 1 分钟 | 关闭超过 10 分钟未支付订单 |
| 退款/售后超时 | 每 5 分钟 | 处理售后超时自动处理 |
| 邮件队列 | 每 1 分钟 | 发送待发邮件（SMTP） |
| 广告到期 | 每日 00:00 | 下线到期广告 |

通过 `php think <command>` 命令实现，crontab 配置示例：
```cron
0 22 * * *  cd /workspace/social/server && php think withdraw:generate
*/1 * * * * cd /workspace/social/server && php think order:close
*/1 * * * * cd /workspace/social/server && php think mail:send
0 0 * * *  cd /workspace/social/server && php think ad:expire
```

## 5. 支付与结算方案

### 5.1 支付网关
- 支持**彩虹易支付** + **码支付**两种接口
- `s_payment_config` 表存配置（JSON），超管后台维护
- **单选开启 + 自动切换**：开启时检测当前接口连通性，不可用自动切换备用

### 5.2 支付流程
```
用户下单 → 创建订单(待支付) → 调用支付网关 → 用户支付
  → 异步回调(验签) → 更新订单状态 → 冻结/入账
  → (10分钟未支付) 定时任务自动关闭
```

### 5.3 费率与结算
- 全局费率（%）存 `s_system_config`，超管配置
- 每笔订单在**原金额上加收费率金额**，商户可选**用户承担或自行承担**
- 货款进入平台余额，22:00 自动生成提现账单，超管审核打款

### 5.4 资金安全
- 所有资金操作记录操作日志
- 提现打款需**二次确认**
- 回调处理加**幂等**（order_no + out_trade_no 防重复）

## 6. 通知方案（SMTP + 站内信）

### 6.1 邮件
- 场景：注册验证、找回密码、商户审核、文章审核、提现打款、订单通知
- 配置存 `s_system_config`，超管后台可视化配置 SMTP
- 模板存 `s_email_template`，后台可编辑
- 用 TP6 队列/定时任务异步发送，避免阻塞

### 6.2 站内信
- 存 `s_notice` 表
- 用户端消息中心拉取，实时性要求低，轮询即可

## 7. 审核机制

### 7.1 可开关审核（超管配置）
- **商户入驻审核**：开启→审核/超管通过/拒绝+理由+邮件通知；关闭→直接开放
- **文章审核**：开启→AI 审核；关闭→审核/超管任一人工审核
- **广告审核**：广告商城上传→审核通过后展示

### 7.2 AI 审核设计
- 预留 AI 审核服务接口（可对接第三方内容安全 API）
- 兜底：始终保留人工审核通道

## 8. 安全方案

| 类别 | 措施 |
|------|------|
| 接口鉴权 | Token（Redis 存储），白名单接口除外 |
| 密码 | bcrypt/password_hash 加密存储 |
| SQL 注入 | TP6 ORM 参数绑定 |
| CSRF | API 无 Cookie 场景不涉及，后台加 Token |
| XSS | 富文本过滤 |
| 限流 | Redis 滑动窗口，登录/验证码/支付接口重点防护 |
| 上传安全 | 校验类型、大小，重命名，隔离目录 |
| 日志 | 后台操作日志、资金操作日志 |
| 传输 | HTTPS |

## 9. 在线更新方案

### 9.1 服务端更新
- 超管后台**拉取 GitHub 最新版本** → 下载代码包
- 更新前**自动备份**当前代码 + 数据库
- **自动执行 SQL 迁移**（迁移失败自动回滚）
- 更新记录存 `s_update_log`

### 9.2 APP 热更新
- 采用 **uni-upgrade-center**（官方升级中心）
- **wgt 资源热更新**：改前端页面/功能无需重新打包上架
- **整包更新**：原生改动时下载新包覆盖

## 10. 前端方案（uniapp）

### 10.1 技术栈
- Vue 3 + Vite + uniapp
- 一套代码编译：Web / H5 / 微信小程序 / 支付宝小程序 / APP

### 10.2 目录结构
```
client/src/
├── pages/            # 页面（首页、文章、商城、我的、商家等）
├── components/       # 通用组件
├── api/              # 接口封装（request 封装、各模块 API）
├── store/            # 状态管理（Pinia）
├── utils/            # 工具（请求、token、格式化）
├── static/           # 静态资源
├── pages.json        # 页面路由/导航配置
├── manifest.json     # 应用配置（多端）
└── uni.scss          # 全局样式变量
```

### 10.3 请求封装
- 统一 `uni.request` 封装
- 自动携带 Token、处理 401 跳转登录
- 统一错误码处理、loading 控制

### 10.4 多端后台
- 超管/审核/商户/客服后台为 **Web 端**（uniapp H5 或独立管理端）

## 11. 部署架构

### 11.1 服务器（生产）
```
Nginx
 ├─ static → client/dist  (H5/Web 静态资源)
 └─ /api  → PHP-FPM → TP6
```

### 11.2 Nginx 关键配置
```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态资源
    root /var/www/social/client/dist;

    # 后端 API
    location /api/ {
        index index.php;
        try_files $uri @tp6;
    }

    location @tp6 {
        fastcgi_pass 127.0.0.1:9000;
        fastcgi_param SCRIPT_FILENAME /workspace/social/server/public/index.php;
        include fastcgi_params;
    }
}
```

### 11.3 环境变量
- 通过 `.env` 管理（数据库、Redis、SMTP、支付等）
- 生产环境关闭 `APP_DEBUG`

## 13. 风险与对策

| 风险 | 对策 |
|------|------|
| 支付掉单/回调失败 | 补单机制 + 幂等处理 |
| 费率加收边界 | 校验价格上限、退款时费率处理 |
| 自动提现误打款 | 操作日志 + 二次确认 |
| 在线更新失败 | 自动备份 + 迁移回滚 |
| AI 审核误判 | 保留人工兜底 |
| 多端回调差异 | 各端支付回调分别配置 |
