# 研究计划

## 用户目标
找出目前需求大的项目（uniapp 或者 php）—— 即在 uniapp 跨端开发生态与 PHP 后端开发生态中，当前（2026 年）市场需求旺盛、可落地的项目类型/方向，帮助用户判断在哪个方向投入开发资源最有可能获得订单或流量。

## 范围
- 行业定义：以 uniapp（基于 Vue.js 的跨端开发框架，覆盖微信小程序、App、H5）与 PHP（含 Laravel/ThinkPHP/Workerman 等）为技术栈的开发外包、SaaS、模板与开源项目市场。
- 包含：
  - uniapp 生态下的高需求项目类型（小程序、多端 App、行业模板、组件库、SaaS 等）
  - PHP 生态下的高需求项目类型（内容管理、电商、SaaS、API 后端、企业应用、即时通信、爬虫等）
  - 两者结合的跨端+后端一体化项目方向
  - 外包接单平台、开源社区、模板市场反映出的需求热度信号
- 不包含：
  - 非 uniapp/PHP 技术栈的项目（如纯 React Native、Flutter、Java、Go、Node 系）
  - 与开发需求无直接关系的 PHP/uniapp 历史、语言演进、社区治理
  - 单家公司深度财务分析
- 地域：以中国市场为主（uniapp 与 PHP 外包模板市场高度集中于国内），兼顾海外开源热度信号
- 资料截止日：2026-08-07
- 历史观察期：以资料截止日可确认的最新完整年度（2025）及最新部分年度（2026）为准，必要时回溯至 2023
- 预测期：无（不要求预测）
- 指定企业或焦点：未指定企业；关注开源项目、模板市场头部作者、外包平台热门品类

## 研究问题

### 市场规模测算（核心）
- uniapp 与 PHP 开发需求整体规模如何？外包接单、模板销售、SaaS 订阅哪条路径需求最大？
- 哪些细分品类（如微信小程序电商、社区团购、本地生活、企业官网、SaaS 多租户、即时通讯）的需求数量/金额占比最高？
- 重要问题：开源项目下载量、GitHub Star、Gitee/GitCode 收藏、模板市场销量等可作为需求热度的代理指标吗？

### 竞争格局分析（核心）
- uniapp 生态中哪些头部开源项目/模板/组件库需求与采用度最高？
- PHP 生态中哪些头部项目（CMS、电商、框架、SaaS 脚手架）需求与采用度最高？
- 重要问题：开源热度与商业外包需求是否一致？哪些是"开源热但接单冷"，哪些是"接单热但开源冷"？

### 趋势、机会与风险（核心）
- 2025-2026 年哪些 uniapp/PHP 项目方向需求在上升、哪些在下降？
- AI 编程、低代码、SaaS 化对 uniapp/PHP 传统外包需求带来什么影响？
- 机会：当前最值得投入的高需求项目方向有哪些？成立条件与观察信号是什么？
- 风险：技术替代、平台政策（如微信小程序规则）、需求萎缩等风险点？

## 假设
- 用户所说的"需求大"以可观测的市场信号（外包接单量、模板销量、开源采用度、招聘 JD、社区活跃度）为衡量依据。
- uniapp 与 PHP 作为成熟但非最热技术栈，其"需求大"更多体现在存量市场与垂直行业的稳定外包/模板需求，而非新兴技术爆发。
- 资料以公开可检索的中文技术社区（Gitee、CSDN、开源中国、掘金、程序员客栈、码市等）与开源平台（GitHub、npm、Packagist）为准。
